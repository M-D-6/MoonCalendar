# Vazirmatn font

`Vazirmatn-Regular.ttf` is bundled and used for the whole app (see lib/ui/theme.dart).
Bold text is synthesised from Regular. For true Medium/Bold weights, download
Vazirmatn from https://github.com/rastikerdar/vazirmatn/releases, copy
`Vazirmatn-Medium.ttf` and `Vazirmatn-Bold.ttf` here and add them (with
`weight: 500` / `weight: 700`) under the `Vazirmatn` family in pubspec.yaml.
